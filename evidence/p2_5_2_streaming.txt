# against Kafka + Mongo + curated Parquet, running inside the `spark` container).
# Date: 2026-09-26.

## Topology confirmed running
Q1 raw: Kafka -> movielens32m/stream/raw_events/ (own checkpoint)
parsed: readStream(raw_events) -> from_json -> broadcast join `movies` -> `reason`
Q3 quarantine: parsed WHERE reason IS NOT NULL -> movielens32m/stream/quarantine/
Q2 valid: parsed WHERE reason IS NULL -> watermark(10min) + dropDuplicatesWithinWatermark(eventId)
          -> foreachBatch(serve_batch) -> curated_ratings (batch writer) + Mongo
