thử lại." (no Kafka, no 503 in the text), card unlocked. Recommendations kept loading while Kafka was down.
Kafka back healthy after 24 s.
Streaming stopped (Kafka up): rating accepted, card "Đang cập nhật gợi ý…", after the poll window the card says
"Đánh giá đã lưu, gợi ý sẽ cập nhật sau." (no pipeline/Kafka wording, stars stay locked). After `start streaming`
the rating was applied ~52 s later (history total 5 -> 6): nothing lost.

## 5. Two-tab story
Tab 1 = An on /app, tab 2 = /admin. Admin created "Phim hình sự mới" (Crime|Drama) -> id 9000004. After a
fresh load An's feed shows it at rank 3, badge "Mới", reason "Mới thêm". Deleted it, then created another:
id 9000005 (never reuses 9000004). A refresh event on An's tab removed the deleted movie and later added the new
one at rank 3 without any click; a second refresh with no change left the DOM nodes untouched.
LIMITATION: in this browser pane document.visibilityState is "hidden" in both tabs and visibilitychange never
fires when tabs are switched, so the refresh handler was exercised by dispatching that event, not by a real tab
switch. The event itself is standard browser behaviour; the handler logic and its guards are what was verified.
Demo movies deleted afterwards (movies back to 87,585).

## 6. Bugs found by running the page, fixed
1. visibilitychange reloaded the feed (with skeleton, replacing every card) on every return to the tab, even
   when nothing changed, and could unlock a card whose rating was pending (double rating possible). Now the
   refresh is silent, redraws only when the list changed, and is skipped while a rating is pending.
2. The pending-rating counter leaked on logout (cancelled polls never decremented it), which blocked every later
   refresh. clearPolls() now resets it.
3. After submitting with the keyboard, focus fell to <body> (the starred button became disabled), and again when
   the feed was redrawn. Focus now stays on the card's status line and returns to the "Dành cho bạn" heading.
4. Star rows were not aligned across cards with different title lengths; the row now sits at the card bottom.
