### Bugs found by running this against real data (fixed, each has a test)
1. Gate detail with a whole Java stack trace (G1-G3 on the unreadable model file) made the panel
   unusable; the API now returns only the first line, max 200 chars (payload 2.3 KB).
2. "Vừa được rate" was logged for movies that were only pushed out of the top-k by the new movie.
   The page now says so only for movies it actually sent a rating for, and groups the rest.
3. Demo movie ids were derived from max(_id) of the movies still present, so after a delete the next
   movie reused the old id and inherited its ratings (user_rated keeps them on purpose). Ids now
   come from a counter that only moves forward (pipeline_state demo_movie_seq). Re-verified on real
   Mongo: ids 9000001, 9000002, then 9000003 after deleting both; Western not shown to 700008 and the
   Crime|Drama control shown at rank 3, i.e. the earlier "Western not shown" result was only valid
   after this fix.
